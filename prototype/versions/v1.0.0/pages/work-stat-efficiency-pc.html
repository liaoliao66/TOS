每日作业量趋势 · 说明
  • 横轴为司机；每个司机并排展示三项：总作业量、总平均量、有效平均量。
  • 纵轴左侧为总作业量（吨），右侧为平均量（吨/小时）；已取消日/周/月切换，时间范围取顶部开班日起止。
  • 总平均量 = 总作业量 ÷ 总时长；有效平均量 = 非零产量合计 ÷ 有效作业时长。
  • 有效作业量：产量不为 0 的填报均计入；有效时长按填报时段计数（最小单位 1 小时），产量为 0 的时段不计入。
  • 货种与机械筛选保留：全部/一级/二级均按当前范围汇总到司机；不再按货种出柱。
  • 已去掉平均/最大/最小基准虚线；数据仅含已通过记录。
