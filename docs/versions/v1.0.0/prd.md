## 一、结论摘要

本版在录入闭环与智能问数基础上，补齐 **作业条件结构化（是否正常作业）**、将原速览升级为 **以师傅为核心的作业效率分析**，并纳入 **企微 H5 填报发起**（审核规则文档化，原型不画审批页）。

| 能力 | 结论 | 优先级 |
|---|---|---|
| 是否正常作业 | 时段×机械位必填；「否」必选原因（沿用现有备注原因字典）；作业量仍可编辑 | P0 |
| 非正常与效率 | 非正常不强制清零作业量；录入侧保留字段。分析页本期不展示异常原因统计与异常维汇总卡 | P0 |
| 作业效率分析 | 菜单更名；核心考核师傅；**必须按货种维度**对比吨/小时（默认单货种出榜）；可再按白/夜班切片 | P0 |
| 日班明细 | 效率分析页内次级 Tab，保留按日班浏览已通过数据能力 | P1 |
| 智能问数 | 保留；可问师傅/货种/班次效率类问题（P1 扩展） | P0/P1 |
| 企微 H5 | 本版包含：单条明细录入、日班单据汇总、提交发起；审核流程写入文档，原型不单独交付审批页 | P0 |
| 审批/消息/权限配置 | 平台承接；本模块原型不画审批中心/消息/权限页 | — |

### 已锁定业务约定

| 约定项 | 结论 |
|---|---|
| 版本策略 | 唯一 v1.0.0 内迭代 |
| 作业量单位 | 吨，保留 2 位小数 |
| 单机效率看板 | 不做；本期做 **师傅效率**（非机械台时效率看板） |
| 泊位–机械 | 固定绑定，每泊位 1～2 台机械 |
| 录入组织方式 | 一人填报全部泊位 |
| 录入粒度 | PC：按「开班日 + 班次」矩阵填满 12 时段；企微：同一单据下逐条明细录入，整单提交 |
| 货种字段 | 全部机械位统一具备货种 |
| 夜班日期 | 归属开班日 |
| 师傅归并 | 按司机字典姓名汇总；一人多机明细带机械 |
| 原因字典 | 沿用现有：停电/无生产作业、吃饭休息、车辆断档、交接班、避高温暂停、下雨暂停、完船；本期不强制加「其他」 |
| 填报后 | 提交后走平台审批；通过后锁定；分析仅消费已通过 |
| 助手默认窗口 | 近 1 个月；超窗询问；本期不导出 |
| 单位时间 | 1 个填报时段格子 = 1 小时 |

## 二、产品概述

### 2.1 产品定位

港口现场 **单机分时段作业量记录、师傅作业效率分析与智能问数** 工具；PC 承担分析与配置，企微承担现场轻量填报与发起。

### 2.2 产品目标

| 目标 | 说明 | 优先级 |
|---|---|---|
| 结构化日班录入 | 含是否正常作业 + 原因 + 可编辑作业量 | P0 |
| 自动汇总 / 填后锁定 | 提交审批通过后锁定 | P0 |
| 作业效率分析 | 按师傅、货种、白/夜班的单位时间作业量考核 | P0 |
| 企微轻量填报发起 | 现场逐条录入明细，日班单据汇总后提交发起 | P0 |
| 智能对话问数 | 自然语言查询已通过数据 | P0 |
| 快捷问数 | 预置日常汇总与效率类快捷 | P1 |
| 字典 / 导出填报 | 司机/货种/原因字典；列表导出 | P1 |

### 2.3 用户角色定义

| 角色 | 职责 | 终端侧重 |
|---|---|---|
| 作业录入员 | 填报、保存、提交发起 | PC + 企微 |
| 数据查看人 | 效率分析、问数、只读写填报 | PC 为主 |
| 基础配置员 | 泊位机械、字典 | 仅 PC |
| 审批人 | 平台审批通过/驳回 | 平台能力；文档描述，原型不画审批页 |

## 四、业务流程

### 4.1 完整业务流程图

```mermaid
flowchart TD
    A[统一登录] --> B{终端}
    B -->|PC/企微| C[日班填报含是否正常作业]
    C --> D[提交发起平台审批]
    D -->|通过| E[单据已通过锁定]
    D -->|驳回| C
    E --> F[作业效率分析-师傅效率]
    E --> G[日班明细Tab]
    E --> H[智能问数]
    B -->|PC| F
    B -->|PC| H
```

**文字解读：** 填报（含条件标记）→ 平台审批 → 已通过数据进入效率分析与问数；企微侧重填报发起，分析在 PC。

### 4.2 子流程：正常/非正常填报

```mermaid
flowchart TD
    A[选择时段×机械位] --> B{是否正常作业}
    B -->|是| C[可填货种与作业量]
    B -->|否| D[必选非正常原因]
    D --> E[作业量仍可编辑]
    E --> F[按货种进入效率分析]
    C --> G[参与汇总与效率统计]
    F --> G
```

**文字解读：** 非正常不等于停工清零；如大风/高温仍可作业但效率下降，需保留作业量，并在分析中与正常条件对比。

### 4.3 用户交互流程图

```mermaid
flowchart TD
    L[填报列表PC/企微] --> E[填报编辑]
    L --> V[填报只读]
    F[作业效率分析] --> T1[师傅效率Tab]
    F --> T2[日班明细Tab]
    T1 --> V
    T2 --> V
    F --> A[智能问数]
    L --> A
    FAB[全局问数悬浮] --> A
    M[泊位机械配置PC]
    D[字典管理PC]
```

### 4.4 填报单状态机

```mermaid
stateDiagram-v2
    [*] --> 草稿: 新建并保存
    草稿 --> 草稿: 再次保存
    草稿 --> 审批中: 提交发起
    审批中 --> 已通过: 平台审批通过
    审批中 --> 已驳回: 平台审批驳回
    已驳回 --> 草稿: 修改后保存
    已驳回 --> 审批中: 再次提交
    已通过 --> [*]
```

**说明：** 效率分析与问数仅消费「已通过」。审批操作由平台承接，本版原型不交付审批页。

### 4.5 企微端数据流转（文档约定）

```mermaid
sequenceDiagram
    participant U as 录入员
    participant WX as 企微H5
    participant P as 平台流程
    participant PC as PC效率分析

    U->>WX: 整单提交审核
    WX->>P: 发起审批
    Note over P: 审核在平台完成(原型不画)
```

**文字解读：** 企微按「一条明细」录入并挂在开班日+班次单据下，录完后整单提交；PC 仍可矩阵录入，字段口径一致。

## 五、功能模块总览

### 5.1 作业填报（增强）

| 维度 | 说明 |
|---|---|
| 功能介绍 | 按开班日+班次录入各机械时段作业；标记是否正常作业及原因 |
| 前置条件 | 统一登录；泊位机械、司机/货种/原因字典已配置 |
| 数据权限 | 录入员编辑草稿/已驳回；他人按角色只读 |
| 页面跳转 | 列表→编辑/只读；提交后回列表看状态 |

矩阵单元格新增：

| 字段 | 规则 | 优先级 |
|---|---|---|
| 是否正常作业 | 必填；默认「是」 | P0 |
| 非正常原因 | 「否」时必填；选项=现有原因字典 | P0 |
| 作业量(吨) | 正常/非正常均可编辑；2 位小数 | P0 |
| 货种 / 司机 | 继承原规则 | P0 |

提交校验：存在「否」且无原因 → 拦截并高亮。

### 5.2～5.4 汇总 / 列表导出 / 基础配置

继承既有能力。字典中「备注原因」对外展示名可调整为「非正常原因」，枚举值不变。

### 5.5 作业效率分析（原已通过数据速览升级）

| 维度 | 说明 |
|---|---|
| 功能介绍 | 基于已通过数据，按货种考核师傅单位时间作业量；跨货种不混排总榜 |
| 前置条件 | 存在已通过填报；统一登录 |
| 数据权限 | 同查看人；强制仅已通过 |
| 页面跳转 | 师傅行/日班行 → 只读写填报；「问数」唤起助手 |

#### 5.5.1 效率口径（产品补充，已锁定方向）

| 指标 | 定义 | 用途 | 优先级 |
|---|---|---|---|
| 单位时间 | 1 时段格子 = 1 小时 | 分母统一 | P0 |
| 时段产量 | 该时段该机械位作业量（吨） | 明细 | P0 |
| 吨/小时 | Σ作业量 ÷ Σ时段数 | **核心考核指标** | P0 |
| 师傅×货种（必选） | 先锁定货种，再在同货种内对师傅排名 | 考核主视角 | P0 |
| 班次切片 | 在选定货种下，可再按白/夜班筛选 | 辅切片 | P0 |

**分析页统计口径（本期锁定）：**

| 统计内容 | 必出指标 | 优先级 |
|---|---|---|
| 当前货种·正常作业 | 平均、最大值、最小值吨/小时；辅：本货种总产量、时段数 | P0 |
| 师傅效率榜 | 仅同货种内排名；列：排名、师傅、货种、班次、产量、时段数、正常均/最大/最小 | P0 |
| 证据折线图 | 横轴开班日、纵轴作业量；平均/最大/最小基准线 + 各师傅每日产量；支持时间与货种筛选（默认单货种） | P0 |
| 异常原因统计分析 | **本期分析页移除，不做** | — |
| 异常维汇总卡 | **本期分析页移除，不做** | — |

**考核原则（产品补充）：**

1. **主考核对象是师傅**；一人多机按司机姓名归并，下钻可看机械。  
2. **主指标是吨/小时**；榜单与证据图 **必须先选定货种**，默认一个货种，禁止跨货种混排为唯一总分。  
3. 分析页以 **正常作业维** 展示效率；录入侧仍保留「是否正常作业 / 原因」，供追溯与后续扩展。  
4. 异常时段产量仍可填报入库，**不因异常清空作业量**；本期不在分析页做异常分原因表。  
5. 不做「单机台时看板」。

#### 5.5.2 页面结构

| Tab/区域 | 内容 | 优先级 |
|---|---|---|
| 筛选条 | 开班日范围、班次、**货种（必选，默认单货种，无「全部」混比）**、泊位、机械、师傅 | P0 |
| 总览卡片（单排） | 本货种总产量；正常维：均/最大/最小吨/小时 | P0 |
| 证据折线图 | 作业日×作业量；平均/最大/最小直线 + 师傅日产量；时间+货种筛选 | P0 |
| Tab「师傅效率」 | 当前货种下一张榜；切换货种后刷新榜与卡片 | P0 |
| Tab「日班明细」 | 按开班日+班次浏览已通过单据与汇总（承接原速览） | P1 |
| 空状态 | 无已通过数据提示 | P0 |
| ~~异常原因明细表~~ | 已移除 | — |

### 5.6 智能问数助手

继承既有能力；结果口径仅已通过。  
P1 扩展问法示例：某师傅近 7 日白班硫矿吨/小时；**某货种**师傅效率排名（须带货种）。

入口：全局醒目悬浮「问数」、效率分析页内按钮；支持全屏。

### 5.7 快捷问数

保留原预置产量类快捷；新增效率类（P1）：

| 快捷名称 | 口径 | 优先级 |
|---|---|---|
| 今日各货种作业量合计 | 继承 | P0 |
| 今日师傅吨/小时榜 | 开班日=今日，**指定货种**后按师傅吨/小时 | P1 |
| 今日白班 vs 夜班吨/小时 | 今日已通过，班次对比 | P1 |

用户自建/改名「我的快捷」规则不变（P0）。

### 5.8 企微 H5（本版纳入）

| 维度 | 说明 |
|---|---|
| 功能介绍 | 现场轻量填报：每次只录一条作业明细，挂在「开班日+班次」日班单据下，汇总后提交审核 |
| 前置条件 | 企微内打开；账号已绑定 |
| 数据权限 | 同录入员 |
| 页面跳转 | 列表→日班单据→添加一条→回单据；单据提交审核后回列表 |
| 与 PC 差异 | **仅企微**改为逐条录入；PC 仍为日班矩阵。数据字段一致，审批状态机一致 |

| 包含页面（原型交付） | 不包含（仅文档） |
|---|---|
| 填报列表、日班单据（明细汇总）、单条录入、只读详情 | 审批待办操作页、通过/驳回按钮页、消息中心、配置、效率分析、问数 |

#### 5.8.1 单条明细字段（P0）

| 字段 | 规则 |
|---|---|
| 时段 | 必选（12 时段之一） |
| 泊位 / 机械 | 必选；机械随泊位带出 |
| 师傅（司机） | 必选 |
| 货种 | 必选 |
| 作业量(吨) | 必填，≥0，2 位小数；非正常亦可填 |
| 是否正常作业 | 默认正常；否时原因必选 |

#### 5.8.2 日班单据与提交（P0）

| 规则 | 说明 |
|---|---|
| 单据粒度 | 开班日 + 班次；其下挂多条明细 |
| 录入节奏 | 每次打开「添加一条」只录一条；可连续「保存并继续添加」 |
| 提交审核 | 在日班单据页对**整单**发起；至少 1 条明细；非正常缺原因拦截 |
| 审批 | 平台处理；原型仅到「提交审核」，不画审批页 |

## 六、字段与汇总规则

### 6.1 填报字段

| 层级 | 字段 | 规则 |
|---|---|---|
| 单头 | 开班日、班次（白/夜） | 必填；夜班归属开班日 |
| 明细 | 泊位、机械、司机、货种 | 机械随泊位带出；司机可选字典 |
| 明细 | 12 时段作业量 | 吨，2 位小数；正常/非正常均可填 |
| 明细 | 是否正常作业 | 是/否，默认是 |
| 明细 | 非正常原因 | 否时必填；字典枚举 |
| 汇总 | 班次小计、日合计 | 产量合计口径不变 |

### 6.2 效率结果展示字段

| 场景 | 列表示例 |
|---|---|
| 师傅效率榜（按货种） | 排名、师傅、货种、班次、产量(吨)、时段数、正常平均/最大/最小吨/小时 |
| 班次切片 | 在选定货种下：师傅、班次、吨/小时、产量、时段数 |
| 证据折线数据点 | 开班日、师傅、货种、当日作业量；另含该货种平均/最大/最小基准 |

### 6.3 问数结果字段

继承产量类；效率类增加吨/小时、班次、货种、是否正常作业等列。

## 七、用户交互路径

### 7.1 正常流程：PC 填报含条件标记

1. 打开填报编辑 → 各时段默认「正常作业」。  
2. 遇大风仍作业：选「否」→ 选原因（如避高温/下雨等现有项）→ 仍填写实际作业量。  
3. 提交发起 → 平台审批通过 → 进入效率分析。

### 7.2 正常流程：师傅效率分析

1. 侧栏进入「作业效率分析」。  
2. 默认 Tab「师傅效率」，**货种默认一个（如氧化钙）**，可切换班次。  
3. 查看本货种总览卡片、证据折线图、师傅效率榜（同货种内排序）。  
4. 切换货种后，卡片/折线/榜单一并刷新。  
5. 点击师傅下钻明细 → 只读写填报单。

### 7.3 正常流程：企微填报发起

1. 企微入口进入填报列表 → 新建/打开日班单据。  
2. 点击「添加一条」填写时段、泊位/机械、师傅、货种、作业量、是否正常（及原因）→ 保存回单据。  
3. 可继续添加多条；录完后在日班单据页点击「提交审核」。  
4. 列表查看审批中/已通过/已驳回状态（审核动作在平台，本原型不画）。

### 7.4 边界情况

| 边界 | 行为 |
|---|---|
| 非正常但作业量为 0 | 允许；分析计入非正常时段 |
| 非正常且作业量 > 0 | 允许入库；本期分析页不单独做异常原因表 |
| 正常但作业量为 0 | 允许；不强制填原因 |
| 一人多机 | 榜单按司机汇总；明细分行显示机械 |
| 企微单据无明细即提交 | 拦截：至少一条明细 |
| 无已通过数据 | 效率分析空状态 |

### 7.5 异常兜底

| 异常 | 行为 |
|---|---|
| 「否」未选原因提交 | 拦截高亮 |
| 提交/加载失败 | 明确文案 + 可重试；草稿保留 |
| 问数超 1 个月 | 先询问再查 |
| 问数失败 | 可重试 + 推荐快捷 |

## 十一、场景说明

### 11.1 正常流程

- 录入员在企微或 PC 完成日班填报（含大风天非正常+实际产量）并提交；通过后，查看人在「作业效率分析」**选定货种**后查看师傅吨/小时榜与证据折线。

### 11.2 边界情况

- 仅白班有某货种：夜班切片对该货种显示空/无数据。  
- 切换货种后榜单排序与产量口径随之变化，不与上一货种混比。  
- 日班明细 Tab 无数据：提示暂无已通过单据。

### 11.3 异常兜底

- 字典原因缺失：仅允许选现有枚举，不开放自由「其他」（本期）。  
- 服务异常：保存失败提示，不丢已输入草稿。

## 十四、待确认

1. 问数时间跨度硬上限（建议最长 12 个月）是否采纳。  
2. 「今日」是否严格=开班日今日（含今日夜班）——当前按开班日口径。  
3. 我的快捷是否允许删除（本期原型先支持创建与改名）。  
4. 极值（最大/最小）是否同时展示对应开班日+班次+时段，便于追溯（建议 P1 下钻）。  
5. 异常原因统计分析是否后续以问数/报表形式单独加回（本期分析页已移除）。
