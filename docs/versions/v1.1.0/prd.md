## 一、结论摘要

v1.1.0 仅承载 **企微 H5**：**作业填报**（机台表 + **时段卡片**，禁止大表）与 **作业记录**（与 PC 作业记录口径一致）。行级「推送企微」与「提交本班审批」相互独立；推送成功后该行锁定，PC 端同步。

| 能力 | 结论 | 优先级 |
|---|---|---|
| 作业填报 | 本班 → 机台表 → 12 张时段卡片；可直填作业量 / 编辑子页 / 发送锁定 | P0 |
| 作业记录 | 近 7 天班次卡片列表；审批中通过/驳回；草稿/驳回继续填报 | P0 |
| 时段编辑子页 | 泊位/机械/时段只读；司机/货种/作业量/是否正常/原因/非正常时长/备注 | P0 |
| 本班审批 | 班次级一次提交；白班/夜班各一次 | P0 |
| 效率分析 / 问数 / 配置 | **不在本版** | — |
| 企微推送配置 | **仍在 v1.0.0 PC**（原型 `work-stat-wecom-push-pc.html`） | P1 |

## 三、功能需求

### 3.1 作业填报（P0）

| 维度 | 说明 |
|---|---|
| 本班上下文 | 选开班日（近 7 天）、班次；可新增机台表（弹窗） |
| 机台表 | 与 PC 工班一致：泊位/机械/司机/货种；编辑/删除规则相同 |
| 时段展示 | **卡片列表**（12 张/表），**禁止横向大表** |
| 卡片 | 时段、正常/非正常标签、司机·货种、作业量输入；底部 **编辑 / 发送** |
| 发送 | 先保存作业量；推送企微并**锁定**；与审批无关 |
| 已推送 | 作业量只读；展示「已推送·不可编辑」 |
| 本班提交 | 底栏「提交本班审批」；至少一张机台表 |

### 3.2 作业记录（P0）

| 维度 | 说明 |
|---|---|
| 筛选 | 开班日、班次、状态 |
| 操作 | 审批中：通过/驳回；草稿/已驳回：继续填报；其他：查看（只读进填报） |
| 展示 | 移动端卡片列表 |

### 3.3 时段编辑子页（P0）

| 字段 | 规则 |
|---|---|
| 泊位 / 机械 / 时段 | 只读 |
| 司机 / 货种 / 作业量 / 是否正常 / 原因 / 非正常时长（分钟） / 备注 | 同 PC 工班行级规则 |
| 保存并推送企微 | 可选；成功后锁定并返回卡片列表 |

**非正常时长**：正整数，**≤60 分钟**；选「其他」须填备注。

## 四、用户交互路径

### 4.1 正常流程：作业填报

1. v1.1.0 入口 → **作业填报** → 选本班 → 新增/进入机台表。  
2. 在**时段卡片**上直填作业量；或点「编辑」进子页。  
3. 点「发送」推送企微并锁定（与审批无关）。  
4. 「提交本班审批」→ 在 **作业记录** 查看状态。

### 4.2 正常流程：作业记录

1. **作业记录** → 筛选 → 审批中：**通过/驳回**（整班一次）。  
2. 草稿/已驳回：**继续填报**；已通过/审批中：**查看**（只读）。

### 4.3 边界情况

| 边界 | 行为 |
|---|---|
| 已推送行 | 不可再编辑；PC/企微同步 |
| 班次审批中/已通过 | 整班只读 |
| 机台表含已推送行 | 不可删除机台表 |
| 本班无机台表即提交 | 拦截 |
| 非正常未填原因/时长或时长>60 | 拦截保存/发送 |

### 4.4 异常兜底

| 异常 | 行为 |
|---|---|
| 企微推送失败（正式） | 行不锁定；提示重试（原型为弹窗示意） |
| 参数缺失进入子页 | 提示并退回列表 |
